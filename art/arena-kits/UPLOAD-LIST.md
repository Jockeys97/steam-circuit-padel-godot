# Upload list — one image per asset (Meshy image-to-3D)

One image = one model. 50 Meshy models (10 per map) + 5 ground textures you use directly in Godot (no Meshy).
Meshy settings per image: Image to 3D, Smart Topology, ~4k faces, 2K texture, bottom origin. Model name = the `mesh name` column, e.g. `torii__hero_landmark`.
Tick a row when the GLB is downloaded; GLBs come back to us via `meshy/inbox/<arena>/<slot>.glb` or the API pull.
