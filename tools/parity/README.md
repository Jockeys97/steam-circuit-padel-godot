# tools/parity — cross-engine digest comparator

Consumer half of slice S1. It ports nothing and knows no Godot: it takes two
**parity-digest streams** and answers *equal, or where exactly does the first
difference appear*.

The producer contract is frozen and read-only:
`scripts/parity-digest.mjs` (sha256
`2b24dd26b20e3b5a856a2368e6425bd4cbd98592d58144e36f2d73b87d26fdcd`), shape per
`docs/wayfinder/tickets/simulation-port-boundary.md` §6, evidence in
`docs/wayfinder/evidence/parity-digest-js.md`.

## The command

```bash
# the Godot half now exists (godot/src/sim/parity_digest_gd.gd); pipe it straight in:
env -u DISPLAY GODOT_SILENCE_ROOT_WARNING=1 /root/tools/godot/Godot_v4.7.2-stable_linux.x86_64 \
  --headless --path godot/ --script res://src/sim/parity_digest_gd.gd \
  -- --seed=12345 --ticks=1440 --every=60 \
  | node tools/parity/parity-compare.mjs tools/parity/parity-digest-seed12345.json -

# or against a captured stream / the harness's --json artifact:
node tools/parity/parity-compare.mjs tools/parity/parity-digest-seed12345.json <stream>
```

Either side may be: a producer's stdout text, its `--json=<path>` artifact, or
`-` for stdin. Formats may differ between the sides (the frozen JSON artifact
compares clean against live stdout — verified).

Exit codes: `0` IDENTICAL, `1` DIVERGED, `2` NOT-COMPARABLE, `3` usage/IO.

**Where the Godot side is run matters**: `--path godot/` makes the engine create
`godot/.godot/` (its import cache). Run it from a copy
(`cp -r godot /tmp/godot-probe`) when the repo must stay byte-untouched; the
comparison result is identical either way.

Reports the first divergence as `tick` + `field` (down to the component for
vectors: `ball.z`, `player.y`), both sides' line numbers, both values, the delta,
and how much of the rest of the stream is a *consequence* of that break rather
than an independent finding.

## Files

| File | Role |
|---|---|
| `parity-stream.mjs` | shared reader/writer of the frozen stream shape (both formats), field table, digest-sha recomputation |
| `parity-compare.mjs` | the comparator CLI (the deliverable) |
| `parity-compare-selftest.mjs` | proves the comparator is right, using real JS data plus injected differences |
| `parity-digest-seed12345.json` | READ-ONLY verified JS artifact (do not modify) |
| `fixtures/` | generated by the self-test: the real JS stream plus one injected difference per case |

## Gate semantics (from §6, kept honest)

- **Discrete, must be bit-identical** (14 fields): `rngState`, `rngCalls`,
  `bounces`, `shotType`, `smashStage`, `points`, `games`, `sets`, `playerScore`,
  `aiScore`, `pointsWon`, `rallyHits`, `serveAttempts`, `longestRally`. These are
  compared here even though the JS harness prints several of them without
  asserting them.
- **Float, engine-dependent** (`ball`, `v`, `spin`, the four paddles): compared
  **exactly by default**, because the `1e-3` in §6 is a *proposal that was never
  measured*. `--tol=0.001` opts into it and the output says so loudly.
- **After a discrete break** the engines legitimately diverge for good (§6: a
  float difference flips `nextRandom(state) < chance`). The comparator counts the
  tail and labels it `CASCADE` — never as separate findings.
- **Not comparable at all** (exit 2, no field walk): a stream that breaks the
  contract (wrong field order, missing/duplicate tick, truncated tail whose
  declared `digestSha256`/`sampledTicks` no longer match), a producer that
  declared `FAIL`, or two streams with different `seed`/`ticks`/`every`.

## Run the proof

```bash
node tools/parity/parity-compare-selftest.mjs
```

34 cases: 7 green (identical streams, both formats, stdin, CRLF, in-tolerance
noise) and 23 red (one injected difference each), plus 4 usage/IO cases. Each red
case asserts the *exact* tick and field of the first divergence. Fixtures are
written to `tools/parity/fixtures/` for manual re-runs.

To prove the suite can actually fail (mutation testing):

```bash
mkdir -p /tmp/hobble && cp tools/parity/parity-stream.mjs tools/parity/parity-compare.mjs /tmp/hobble/
sed -i 's/if (divergence) {/if (false) {/' /tmp/hobble/parity-compare.mjs
PARITY_COMPARE_BIN=/tmp/hobble/parity-compare.mjs node tools/parity/parity-compare-selftest.mjs   # must exit 1
```

## Not proven

- **Agreement is at printed precision.** "IDENTICAL" means identical to the
  digest's 6 decimals at the sampled ticks — not bit-identical float64/float32.
  Sub-5e-7 drift at a sample, or divergence *between* samples, would not show.
- **Two seeds, one segment.** Seeds 12345 and 999, 12 s of match time, 25 samples,
  one point each. Games, sets, tie-breaks, faults and the special are unexercised.
- The `1e-3` tolerance remains unvalidated (implemented, opt-in only); the two real
  runs needed no tolerance at all.
- Nothing here asserts that the JS digest is itself correct — it is the reference
  by definition of this slice.
- The Godot producer is owned by another lane and was still being written when it
  was compared; the comparison is a snapshot, not a frozen release.
