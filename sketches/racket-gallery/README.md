Playable stage (arcade + glass, one full-page picker):

`open sketches/racket-gallery/stage.html`

Or serve the folder and hit:

- http://127.0.0.1:8765/stage.html
- http://127.0.0.1:8765/console.html

## What each file is

**stage.html.** Pick a racket, drag to orbit the 3D stand-in, toggle grip / strings / special, send to a teammate. Steampunk and Country sets. Arrow keys cycle. This is the one to play.

**console.html.** Three interaction families on the same content, desktop and mobile frames.

- Stage: coverflow, racket is the product
- Ladder: magazine rungs, inspect desk on the side
- Bench: loadout-first, send sits next to the model
